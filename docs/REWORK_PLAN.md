# eht_mk2 설계 기록

BTC/ETH USDⓈ-M 선물 자동매매. 이 문서는 **왜 지금 구조가 됐는지**와 **검증에서 배운 것**만 남긴다.
파일 구조와 실행법은 `README.md`.

## 0. 현재 상태

- 라이브: BTC/USDT **1d 국면전환** (BULL 듀얼모멘텀 · BEAR EMA크로스 12/50 · SIDEWAYS Z-Score), 데모 계좌
- 주문: 전량 시장가. SL/TP는 봇 내부 폴링으로 관리 (§5 참조)
- 권고: **A 단독 유지** (§6). 한때 A+B를 권고했으나 B의 성과가 미래 참조로 부풀려진 것이었다

## 4. 검증 방법과 교훈

**방법** — 인샘플 6개월 → 아웃샘플 2개월 롤링 워크포워드. 아웃샘플만 집계한다.
파라미터는 상위 30% 조합의 중앙값(고원)으로 고른다. 전략 선택까지 탐색할 때는
중첩 워크포워드(폴드마다 인샘플만 보고 선택)를 쓴다.

**교훈** — 좋아 보였던 결과는 대부분 오류였다. 크기를 남긴다.

| 착오 | 겉보기 | 교정 후 |
|---|---|---|
| 국면별 전략을 아웃샘플 성적으로 선택 (선택 편향) | 1d +110% | **-47%** |
| 로테이션 엔진이 i봉 종가 신호를 i봉 시가에 체결 (룩어헤드) | 샤프 4.26 | **-0.35** |
| 캐리 리밸런싱이 현금을 음수로 둠 (무이자 차입) | 연 11% | **연 5%** |
| 탐색 축을 9개 → 162개로 확대 (과적합) | — | 아웃샘플 +76% → **+57%** |
| B&H를 폴드별 복리로 이어붙임 (구간 사이 공백 누락) | B&H +53% | **+73%** |
| 결합 비교의 '공통구간'이 결측을 0으로 채운 합집합이었음 | A+B+C+D 샤프 0.96 | **1.10** (같은 비용, 진짜 공통구간 2.62년) |
| 변동성 사이징·ATR 손절이 진입 봉 자신의 값(`rv[i]`, `atr[i]`)을 사용 (미래 참조) | B 연 24.2%, 샤프 0.72 | **연 1.5%, 샤프 0.04** |
| 라이브 A가 국면 전환 당일 바로 재진입 (백테스트는 다음 봉부터) | 399일 중 17일 불일치 | **0건** |
| 데이터를 8개월 늘림 | 샤프 0.98 | **0.83** — 이 규모의 샤프는 ±0.15씩 움직인다 |

**비용 기준** — 초기에는 "비용 2배에서도 수익" 을 합격선으로 썼다.
그런데 실측해 보니 BTCUSDT는 $50만 시장가도 충격 0.1bp라, 보수 프로필 슬리피지(1d 편도 7.8bp)가
이미 수십 배 비관적이었다. 비용 2배는 1d 기준 현실 비용의 약 4.7배다.
고회전 전략을 과하게 탈락시키는 기준이었으므로 **현실 프로필 + 1.5배 여유**로 바꿨다.
단 실계좌 수수료(0.05%)가 데모(0.04%)보다 높다는 점은 반대 방향으로 반영한다.

## 5. 운영상 알려진 문제

- **데모 계좌는 조건부 주문(STOP_MARKET/TAKE_PROFIT_MARKET)을 만들지 않는다.** ID까지 돌려주지만
  주문 이력에 남지 않는다. 봇이 이를 감지해 경고하고, SL/TP는 30초 폴링으로만 관리된다.
  → 봇이 멈추면 포지션이 무방비다. 하트비트 감시 필수. 실계좌에서는 거래소 스탑이 동작한다
- `RegimeLiveTrader`가 `super().__init__()`을 부르지 않는다. 새 상태는 `LiveTrader`의 클래스 속성으로 둘 것
- 데스크탑(WSL)은 ssh가 끊기면 배포판 전체가 내려간다 (tmux·nohup 모두 소용없음). 긴 작업은 연결을 유지한 채 돌린다

## 6. 전략 탐색 결과와 권고

**타임프레임** — 1h~3d 전수 탐색. 국면별 전략을 탐색해 조합하는 방식은 중첩 워크포워드에서
**전 타임프레임 손실**이었다. 남은 건 1d 국면전환뿐이다. 차이를 만든 건
회전율이다 — 4h 이하에서는 비용이 신호를 넘는다. 현실 비용으로 다시 봐도 4h 국면전환(E)은 샤프 0.39다.
즉 비용 기준을 완화해도 탈락했던 단기 전략이 살아나지는 않았다.

**계열별**

| 계열 | 결과 |
|---|---|
| 변동성 타겟팅 | 낙폭은 확실히 줄인다 (ETH 1d -68% → -45%, BTC 4h -52% → -38%). 샤프 개선은 +0.1 안팎으로 작다 |
| ATR 손절 | 효과 불분명 (종목·주기에 따라 엇갈림) |
| BTC/ETH 횡단면 로테이션 | 전 TF 샤프 음수 — 종목 교체 비용이 이득을 먹는다 |
| 펀딩 방향 베팅 · 급변 후 역추세 | 실패 |
| 델타중립 캐리 (현물 롱 + 선물 숏) | 연 5% (lev3), 무위험 대비 초과 1.3%. 샤프 12는 꼬리위험(거래소 파산·ADL)이 표본에 없어서 나온 착시. 레버리지 5배부터 청산 |

앞서 변동성타겟 추세 계열(B·C·D)이 "생존자 대부분"이라고 기록했던 수치는 진입 봉
미래 참조 때문에 부풀려진 것이다. 엔진 수정 후 B(ETH 1d)는 워크포워드 샤프 0.04다.
C·D는 수정 후 재검증하지 않았다.

**재검증 결과** — 엔진 수정 후, 현실 비용, 2023-03-15 ~ 2026-09-14 (3.50년)

| 구성 | 연환산 | 샤프 | MDD | 비용1.5배 샤프 |
|---|---|---|---|---|
| **A 단독** | **28.6%** | **1.13** | **-27.3%** | 0.85 |
| B 단독 | 1.5% | 0.04 | -50.0% | 0.03 |
| A+B | 16.4% | 0.69 | -21.6% | 0.53 |

샤프 2 이상에 높은 수익을 내는 조합은 없었다. 샤프(초과수익 기준)는 레버리지로 바뀌지 않는다.

### 권고: A 단독 (BTC/USDT 1d 국면전환)

- 재검증 후에도 유일하게 버틴 전략이다. 변동성 타겟팅·ATR 손절을 쓰지 않아 이번 미래 참조와 무관하다
- 라이브 판단 경로를 백테스트 신호와 대조하는 재생 테스트에서 최근 399일 불일치 0건
- 기대치: 연 25~30%, 최대낙폭 -27% 이상 (실전은 백테스트보다 나쁘다고 볼 것). 2024~2025처럼 손실 연도가 있다
- 수익은 보유 대비 크게 낫지 않다. 쓸 이유는 하락장 방어다

### 모의 → 실계좌 판단 기준

모의 수익으로 판단하지 않는다. 일봉 전략은 연 25~40회 거래라, 샤프 1 전략도 1년
실적으로는 운과 구분되지 않는다. 모의 기간에 확인할 것은 **실행이 백테스트와 같은가**다.

1. 매 거래가 같은 날짜 백테스트 신호와 일치하는지 (재생 대조)
2. 체결가와 백테스트 가정의 차이 (슬리피지·수수료)
3. 봇이 멈추지 않는지 (하트비트), 손절이 제때 나가는지

이게 확인되면 감당 가능한 손실(-40% 가정) 기준으로 작은 금액부터 실계좌에 올린다.
실계좌는 수수료가 0.05%(데모 0.04%)이고, 거래소 스탑 주문이 실제로 동작한다.
