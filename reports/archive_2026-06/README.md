# 2026-06 리포트 (보관용)

이 폴더의 문서들은 **구버전 백테스트 엔진**으로 만든 것이라 수치를 신뢰할 수 없다.
기록 보존 목적으로만 남긴다.

구엔진의 문제 (자세한 내용은 `docs/REWORK_PLAN.md` 부록 A):

- 펀딩비를 전혀 반영하지 않았다
- 슬리피지가 장세와 무관한 고정 0.02%였다
- 봉 안에서 SL/TP를 시가 체결보다 **먼저** 처리해 시간 순서가 뒤집혀 있었다
- 진입한 봉에서는 SL/TP를 검사하지 않아 낙관적이었다
- 청산가 근사가 레버리지에 대해 부호부터 틀려 있었다
- 수량/가격 정밀도와 최소명목가를 검사하지 않았다
- 국면 확정 없이 원시 국면을 그대로 썼다 (라이브와 다른 경로)
- `RegimeSwitchingStrategy`가 설정 파일을 무시하고 기본 파라미터로 돌았다

또한 이 리포트들은 **전 구간 최적화 후 전 구간 성과**를 보고한다.
과최적화를 성과로 착각하는 방식이라, 현재는 워크포워드(인샘플 6개월 →
아웃샘플 2개월)로 대체했다.

현재 유효한 결과는 `reports/wfa_*.md` 를 볼 것.
